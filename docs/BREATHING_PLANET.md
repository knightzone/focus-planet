# 呼吸小星球 · 星球充能

2026-09-13。保留游戏 ID 与持续注意维度，替换旧版自动呼吸后点击确认的玩法。

- 每轮 3 秒扩张、4 秒收缩、1 秒反馈，各档固定节奏，没有停留/憋气阶段。提示自然舒适跟随，不测量真实呼吸。
- 扩张时按住星球充能，松开释放星光。有效按住至少 300ms 并松开，得到基础星光；按下及时、至少按住 1200ms 且松开接近转换点，额外获得星环。
- 每连续 3 轮准确操作获得一条星座连线；失误只结束当前连击，不扣已有奖励。不操作、仅点击或始终不松手，不自动得分。
- 目标循环数：8/9/10/12/14/15/15/15/18/20，正常总时长 64–160 秒。
- 1–10 档转换容差：±1500/1400/1300/1200/1100/1000/1000/950/850/750ms；前六档全程提示，后四档仅前5/3/3/2轮显示明确的按住/松开引导，始终保留星球大小变化。
- 通用暂停冻结活动时钟。恢复时重做尚未结算的一轮，物理触摸需重新按下；已结算的反馈阶段继续，不重复发奖。主动暂停重试会增加活动总时长。
- 分数 =（基础星光数 + 准确星环数）/（轮数×2）；accuracy 为准确轮数占比，reaction 为有效轮次松开时刻相对转换点的绝对偏差（ms），不是医学呼吸指标。未完成退出不提交成绩。

## UI 与素材

复用 `shadow-match-sky-v1.webp` 浅蓝云朵星空、`sky-planets/lavender-ring.webp` 透明卡通星球及 `star-four-point-gold-v1.svg` 星光，不新增位图、不增加大图包体。白色 65% 不透明核心区；按住柔和光晕、松开星光飞出，完成轮次逐步点亮周围星星，稳定操作增加星环和连线。小屏可滚动。

## 验证

`tools/test-breathing-planet.cjs` 覆盖 10 档共 136 轮满分流程、难度单调性、无操作、提前松手、重复开始/松手、触摸取消、暂停恢复、反馈阶段暂停不重复发奖、卸载清理及容差边界。通用暂停回归继续使用 `tools/test-training-pause.cjs`。

浏览器近似预览已检查准备页、运行阶段、减少提示、无操作不发奖及暂停弹层，不代替真机触摸验收。Android/iOS 5.25 Vapor 编译导出通过，Xcode 同步及资源新鲜度校验通过。真机重点：长按是否被系统/滚动打断、跨越吸呼转换时松手、双指误触、中途切后台、低档与高档的操作容差体验。
