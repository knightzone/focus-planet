# 单机版完善计划

## 已完成的基础闭环

- 单儿童档案与四档年龄模式
- 五维训练目录与 20 个游戏槽位
- 星星捕手完整训练、结果与本地记录
- 档案编辑、训练历史、真实连续天数和本地数据清理
- 五类训练表现概览

## 第二批：五维各有一个代表游戏（已完成）

1. 持续注意：星空守望员（已完成 MVP）
2. 选择注意：颜色指令（已完成 MVP）；森林寻宝待 AI 素材通过审核后补充
3. 转换注意：魔法规则（已完成 MVP）
4. 分配注意：听声找图
5. 为星星捕手补充年龄难度参数

完成情况：规划目录中的 20 个游戏已全部可玩，并统一接入结算、记录和报告。暂停、主动退出与异常恢复将在整体质量优化阶段统一处理。

当前五个维度均已有至少一个可玩 MVP；影子配对与森林寻宝也已加入，森林寻宝暂用可替换对象占位。

## 第三批：每日训练计划

- 按年龄生成 3 个训练环节
- 记录计划完成状态
- 支持中断后继续
- 每日首次完成奖励
- 温和的休息提醒，不使用惩罚式连续打卡

## 第四批：内容与适龄化

- 3–6 岁语音引导、大触控区域、无阅读要求
- 7–9 岁基础规则和即时示范
- 10–12 岁增加干扰、速度与记忆负荷
- 13–16 岁弱化卡通元素并增加学习场景
- 音效、触感反馈、动效开关和静音模式

## 第五批：报告可信度

- 保存原始指标及表现波动，不只保存合成分数
- 区分首次熟悉、正常训练和无效局次
- 展示个人趋势，不与其他儿童比较
- 在专业验证前统一使用“训练表现”，不使用“诊断”或“能力测定”

## 第六批：单机发布质量

- 数据 schema 迁移测试与异常数据恢复
- 应用前后台、来电和锁屏中断处理
- 横竖屏策略、安全区和大小屏适配
- 无障碍字体、色觉方案与屏幕阅读
- Android、iOS、HarmonyOS NEXT 真机测试矩阵
- 隐私说明、家长入口、使用时长和休息控制
