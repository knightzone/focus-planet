# 找茬关卡素材方案

## 关卡结构

每个关卡由两张同尺寸图片和一组归一化热点组成：

```uts
type DifferenceHotspot = {
  x: number, // 0-100，热点中心相对图片宽度
  y: number, // 0-100，热点中心相对图片高度
  radius: number
}

type SpotLevel = {
  id: string,
  imageA: string,
  imageB: string,
  recommendedAge: number,
  differences: DifferenceHotspot[]
}
```

页面只读取图片和热点，不把具体场景写进玩法代码。首关素材位于：

- `static/images/runtime/spot-difference/spot-park-a-v1.png`
- `static/images/runtime/spot-difference/spot-park-b-v1.png`

## 素材规格

- 画布：`16:9`，项目内统一保存为 `1024 x 576` PNG。
- 构图：主体完整、色块清楚、不要在边缘放关键差异。
- 差异：每关只改变明确物件，避免全图重绘造成伪差异。
- 热点：点击区域至少覆盖视觉目标，并保留约 12% 的容错范围。
- 文案：图片内不放文字，低龄儿童可以只通过图形完成。

## 难度分级

- 3-5 岁：3 处差异；颜色变化、增减物件、明显方向变化。
- 6-8 岁：4 处差异；大小、数量、位置和局部形状变化。
- 9 岁以上：5-6 处差异；加入相似干扰物，但不使用极小像素差。

## 批量生产建议

1. 先确定场景系列，例如公园、海底、太空、农场、城市，每个系列制作 8-12 个基础场景。
2. 锁定基础图后再逐项编辑 B 图，每次只改预先列出的物件。
3. 用图像对比工具检查 B 图，排除非目标区域的意外变化。
4. 在内部标注工具中点击差异中心，导出百分比坐标和半径。
5. 真机验证小屏点击容错后，再把关卡加入内容清单。

首批建议制作 5 个主题、每个主题 10 关，共 50 关。图片可以随版本内置；后续若增加在线内容，再把同一份关卡结构迁移到远程清单即可。
