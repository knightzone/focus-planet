# 记忆连线

2026-09-20。gameId `memory-link`，dimensionId `focused`（记忆辨识），路由 `/pages/game/memory-link`。

## 玩法

- 进入准备页不自动计时，可先试一轮或直接开始；试玩固定3个，不计分、不保存成绩。
- 每轮从影子配对彩图的同一组内无重复抽取图形，随机对应1至N的数字，不使用影子。记忆结束仅隐藏连线，原图节点保持可见并用700ms动画换位；右侧数字不重排，800ms后才计作答时间。动画可暂停，每个图形均离开原位置，不重新生成题目。
- 点图形再点数字，或拖动到数字；一对一连线，可改答案，全部连好后统一提交。不即时透露哪根线正确。
- 整轮全部连对才算成功，否则（包括作答超时）算一次失败；成功后连续失败清零，达到容错上限结束训练。结果展示正确对应1.8秒。
- 总时长包含记忆、作答和回顾，暂停不计时。总时间到时当前未提交轮中立丢弃，仅计算已判定轮；没有已判定轮则0分。
- 复用云背景，使用2026-09-21新增的独立记忆连线封面（对齐旧画风v2）。6个图形时只抽取素材足够的组。

## 计分和接入

- 单轮部分正确：向下取整（100×正确数÷图形数）；全对至少100分。在每图形3.5秒的回忆目标内完成时按节省时间比例奖励，最高200分。
- 整局取轮次平均。若耗尽连续失败容错，各轮结算上限99，确保失败结束不会触发升级；正常完成按统一100分通关规则。星级、能量、结算角色和报告复用公共逻辑。
- 服务端目录/出题白名单需新增 `memory-link`，归属 `focused`，10档，最高200分；本次仅修改客户端，不代表服务端已部署。
