# 记忆连线

2026-09-20。gameId `memory-link`，dimensionId `focused`（记忆辨识），路由 `/pages/game/memory-link`。

## 玩法

- 进入准备页不自动计时，可先试一轮或直接开始；试玩固定3个，不计分、不保存成绩。
- 记忆阶段的剩余时间用**进度条**呈现（按本轮记忆总时长从满格递减到空，宽度 100ms 更新一次），不再显示数字倒数；到点后进入换位动画与作答。
- 每轮从影子配对彩图的同一组内无重复抽取图形，随机对应1至N的数字，不使用影子。记忆结束仅隐藏连线，原图节点保持可见并用700ms动画换位；右侧数字不重排，800ms后才计作答时间。动画可暂停，每个图形均离开原位置，不重新生成题目。
- 点图形再点数字，或拖动到数字；一对一连线。**每次连线立刻判定对错**：连对变绿并锁定（不能取消，别的行也抢不走这个数字），连错变红、计一次错误，红色那行点一下图形（或点那个红色数字）即可取消重连。
- 全部连对后**自动进入回顾**，不再需要手动提交；回顾展示正确对应 1.8 秒。作答超时算一次未通过；连对后连续未通过清零，达到容错上限结束训练。
- 总时长包含记忆、作答和回顾，暂停不计时。总时间到时当前未提交轮中立丢弃，仅计算已判定轮；没有已判定轮则0分。
- 复用云背景，使用2026-09-21新增的独立记忆连线封面（对齐旧画风v2）。6个图形时只抽取素材足够的组。

## 计分和接入

- 单轮按**错误次数**计分（与上天入海同口径的「起始分 − 扣分」模型）：**起始 120，每错一次扣 10 分，下限 0** —— 0/1/2 次错误 = 120/110/100，错两次仍到过关线（允许小错），3 次起低于 100；错 12 次起为 0。作答超时记 0 分并计一次未通过。不再按回忆速度加分。
- 上报的 accuracy 为「一次就连对的比例」= 总对数 ÷（总对数 + 总错误数）；reaction 仍为本轮作答耗时均值。
- 整局取轮次平均。若耗尽连续失败容错，各轮结算上限99，确保失败结束不会触发升级；正常完成按统一100分通关规则。星级、能量、结算角色和报告复用公共逻辑。
- 服务端目录/出题白名单需新增 `memory-link`，归属 `focused`，10档，分数范围0–200（本轮起始120、按错误扣分，实际最高120）；本次仅修改客户端，不代表服务端已部署。
