# 听音节奏：声音匹配版

2026-09-13。保留游戏 ID `audio-sequence` 和持续注意维度，替换旧的“按图案复现顺序”玩法。

## 规则

1. 准备页点击开始。目标声音固定播放 2 次，由播放完成事件推进，不能重听目标。
2. 两次结束后显示候选音乐键。点击左侧音乐键试听；点击右侧“选这个”立即作答，不要求听完或听过全部选项。
3. 每轮只记一次答案。确认后停止播放，反馈后进入下一轮；一局 8 轮，目标从声音池中随机无放回抽取，局内不重复。新一局重新抽取，不保证跨局完全不重复。
4. 暂停沿用通用框架，冻结播放和计时；继续恢复原播放，不重放目标、不增加播放次数。未开始返回直接离开。
5. 目标播放失败/超时进入不计分错误状态，可重新训练；不暗中补放目标。选项播放失败可以重新试听该选项。

## 难度与声音

1–10 级选项数为 `2,2,3,3,3,4,4,4,5,5`。低级从明显不同的候选中选干扰，高级逐渐选择相似的候选。没有倒计时抢答，也没有通过细微音高差制造难度。

216 段程序合成的柔和音效 = 6 种乐器音色 × 6 个音高 × 6 个节奏，数量为原 54 段的 4 倍：

- 音高 C4 / E4 / G4 / C5 / E5 / G5，相邻至少 3 个半音，非微小音分差。
- 音色为铃音、木琴、笛音、拨弦、簧管、风琴的合成近似，非真实乐器录音。低级优先选择音色差异明显的干扰；最高级保持同音色，从更接近的音高/节奏中选干扰，但至少保留一个明确可听的不同点。
- 节奏：单短音 400ms、单长音 950ms、短短 320/320ms、短长 320/780ms、长短 780/320ms、三短音 300/300/300ms；多音间隔 220ms。
- 同一节奏不同音区，或同一音区不同音长/音数/次序，确保候选存在实质可听差异。
- 候选颜色按随机位置分配，不与音高或正确答案固定对应。
- 以上是产品设计参数，不是经过儿童听觉实验验证的阈值。须在普通手机外放/耳机上试低、高级，按实际反馈继续调相似度。

素材由 `tools/build-audio-match.cjs` 生成至 `static/audio/audio-match`，无外部采样。216 个单声道 MP3 合计约 2.42MiB；22.05kHz、64kbps，音头/尾淡入淡出。保留原有 54 段，只补充 162 段，约增加 1.81MiB 运行资源。`tools/test-audio-match-assets.cjs` 校验文件数量、重复哈希、全部 MP3 解码、非静音/无削波及六种基音。旧版 18 段音效保留在 `content/audio-match/legacy-v1`，不进入运行资源。其他游戏既有音效未改动。
