## 一句话主线

跃跃和暖暖想办一场“让每个人都开心”的星光游园会，于是和星伴出门寻找好点子。他们一路想把好东西带回家，却发现风装不进口袋、泡泡留不住——最后带回来的，是能和朋友一起重新体验的玩法与故事。

## 故事的味道

欢快、乐观，有一点小冒失和朋友间的机灵接话。没有大反派、危险任务和刻意说教；困难来自日常小意外，通过尝试和互相帮忙解决。

- **跃跃**：点子多，行动快，总想找到“最不得了的东西”；后来发现，小事情也很好玩。不是一直犯错，也会主动想办法。
- **暖暖**：温柔细心，但不是说教的老师；会接玩笑，也会动手尝试，擅长把散落的点子变成可玩的东西。
- **星伴**：想把游园会照得特别亮，后来找到自己的本领——让该亮的地方，亮得刚刚好。
- **团团 / 栗栗 / 点点**：沿途分段参与的老朋友，分别带来动手帮忙、收藏发现和水边生活的小趣味；不要求所有角色每幅同时出现。

## 起承转合

- **起｜1—3章**：想保存快乐 → 决定办游园会 → 带着“找大宝贝”的期待出发。
- **承｜4—8章**：不断发现，也不断遇到“带不走”的东西 → 开始收集玩法，而不只是物品。
- **转｜9—13章**：雨天、歪作品、慢脚步让原计划发生变化 → 发现不完美、停下来、有人陪，同样能很好玩。
- **合｜14—15章**：把发现变成大家能参与的小活动 → 好心情不是收藏好了，而是被重新分享出来。

## 几个轻轻贯穿的呼应

1. **“最不得了的东西”**：开头总想找到一个特别大的惊喜；结尾不再评选第一名，每人喜欢的时刻都算数。
2. **跃跃的结**：邀请信上的结太复杂 → 路上学会实用绳结 → 回来帮忙固定装饰，成长通过动作表现。
3. **“再坐一下”**：菜园里偶然发现的阴凉 → 湖边体会歇脚的舒服 → 成为游园会里认真布置的小角落。
4. **星伴的光**：想照得特别亮 → 见过小桥、灯塔和纸屏 → 最后给不同地方留下恰好的光。
5. **空位**：旅途中总想填满袋子 → 结尾愿意给纪念册留一页。不是少了什么，是还可以有下一次。

## 结尾的感觉

游园会结束，跃跃问：“我们把好心情带回来了吗？”

暖暖看看还在轻轻摇的小旗：“你听。”

远处又传来一阵笑声。

跃跃放心地合上纪念册：“带回来了，好像还变多了。”
