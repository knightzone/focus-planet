# 图案侦探

2026-09-13：原“字符侦探”改名，内部ID仍为 `symbol-detective`，路由、服务端别名和历史记录关联不变。

玩法为找齐和大多数不同的图案，不是始终只有一个。图案总量按10档为9/12/16/20/25/30/36/42/48/48，列数为3/3/4/4/5/5/6/6/6/6，不同目标数为1/2/2/3/3/4/5/6/7/8。最高6列8行，适配竖屏，避免8列导致图片过窄。

复用影子系列137张彩色图和20张星球图素材池（非黑色剪影），不新增运行图片。每三轮一轮星球；低档明显差异，高档开放相似图组。同一轮多数图相同，其他位置均为目标，目标图本身可以重复；以目标位置计数。

桌面大背景、浅白核心层，入口4张实图可选试玩，能直接开始。选对标绿、误点标浅红，不提前揭晓其他目标；角标显示已找到/目标总数，找齐后520ms进入下一轮。试玩不计成绩。

竞速计分仍为0–200，每轮目标时间=原单目标时间×目标数量（每目标6500→4000ms）。轮分=竞速分×目标数/(目标数+误点数)，再四舍五入；多轮平均。重复点同一已判定位置忽略；正确率按实际找到目标/(找到目标+误点)计算。暂停不计搜索时间，不自动提交未找齐的轮次。找出变化、记忆搜索分支不改玩法。

验证：`test-spot-change.cjs` 覆盖10档、唯一多数图/多目标数量、全部完成、重复点击/误点惩罚、试玩隔离、暂停/卸载及兄弟模式；`test-spot-change-assets.cjs` 验证157路径与7200素材组合。浏览器最高48格预览通过，双端编译及Xcode同步状态见路线图；真机点击与辨认体验待验收。
