# 顺序猜猜

2026-09-20。gameId `order-guess`，dimensionId `alternating`（逻辑空间），路由 `/pages/game/order-guess`。

## 规则

- 从影子配对一个彩图组抽取3—6张不重复图片，生成本轮固定隐藏顺序；整个游戏不展示答案、不使用影子，不混组。
- 开局随机排列严格满足档位规定的正确位置数，立即显示正确／错误数量；不标记具体哪张正确。开局线索免费，不算尝试。
- 点两张图片交换位置，可交换多次后提交。提交新排列算一次尝试，显示正确／错误数量，保留每次完整排列及反馈。调整中不实时计算正确数。
- 不允许重复提交本轮已试过的排列（包括开局），防止重复扣次数；全部正确后手动进入下一轮。每轮重新选图、生成答案。
- 可选3图试玩或直接开始，试玩不写成绩；统一暂停／继续／重来／退出。无时间限制、不按速度计分，也不设猜错立即失败规则。
- 复用桌面背景，使用2026-09-21新增的独立顺序猜猜封面（对齐旧画风v2）。

## 计分与服务端

先计算全部轮次的平均尝试数，再计算 `floor(clamp(200 − 100 × 平均次数 / 目标次数, 0, 200))`。等于目标恰好100分，高于目标不足100；更少尝试获得超额分。不同轮次可以相互补偿。不采用各轮倒数或封顶分的平均，以免偏离次数目标。

所有轮都猜对才结算；结算 `accuracy=100` 表示最终排列全部完成，通关与否仍看效率分；`reaction=0` 表示不考核反应速度。为兼容现有结算重算流程，`roundScores` 只传一个汇总效率分，不伪装成逐轮分数。逐轮次数与平均数当前仅在本局页面显示，未新增报告/API次数字段。

服务端需登记 `order-guess`、`alternating`、10档、最高200分并纳入可选训练目录。本次不代表后端已同步部署，不修改历史数据。
