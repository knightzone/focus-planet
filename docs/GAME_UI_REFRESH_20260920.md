## 扩展：全训练准备／试玩统一

覆盖 28 个训练、27 个游戏页面（找出变化和图案侦探共用页面）。以呼吸小星球为视觉基准：半透明白色圆角卡片、薰衣草紫主按钮、浅色次按钮。保留各游戏实际可操作的示范，不改评分、计时、难度或题库规则。

- `TrainingFrame` 统一接收真实 `difficulty` 和 `preparing` 状态。准备／试玩时右上角显示难度，正式训练时同一位置保留暂停；左上角返回行为不变。
- 所有已有开始按钮统一为“开始训练”，原有跳过试玩入口保留；点球仍直接训练。用户复核后补齐找茬乐园的独立两处差异试玩，可跳过／重试，不计成绩或消耗正式题库。
- 不强制把棋盘、听音选项、驾驶操作塞进同一种几何布局，只统一外层视觉和操作层级。
- 320px 小屏的倒水试管最小宽度微调为38px，加外侧间距后不横向溢出。
