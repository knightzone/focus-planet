# 规律小侦探 · 1–10 档难度阶梯（实现记录）

2026-09-17。按外部产出的设计文档《规律补全_1-10档难度阶梯设计》重做难度。
生成器 `utils/pattern-find-levels.uts`，页面 `pages/game/pattern-find.uvue`，回归 `tools/test-pattern-find.cjs`，预览 `tools/preview-pattern-find.cjs`。

## 核心原则

**档位 = 参数**：每档由「素材相似度层级 / 规律族池 / 问号位置 / 选项数 / 形近干扰项数 / 提示强度 / 影子维度」决定；
**一局固定 5 题**，不再用题量当难度；难度只由单题认知负荷决定。

## 3. 规律族

| 族 | 单元 | 形态系数 u | 结构 |
|---|---|---|---|
| F1 | `AB` | 0 | 交替 |
| F2 | `AAB` / `ABB` | 0 | 两符号重复 |
| F3 | `ABC` | 0.5 | 三符号全新 |
| F4 | `AABC` | 0.5 | 长四 |
| F5 | `ABBC` / `ABCB` / `AABB` / **`ABBA`** | 1.0 | 回环（含回文单元） |
| F6 | `A'BCB` / `ABCB'` / `A'ABB` / `AABB'` | 1.0 | 影子绑定（`'` 表示该位用影子版） |
| F7 | 影子移动 / 影子递增 | 1.5 | 显示 3 遍，问第 4 遍首格 |
| F8 | 块递增 `A BB CCC DDDD` | 1.5 | 显示前 9 格，问第 10 格 |

- 族的**单元串里 `'` 写在字母后面**（`A'` = A 用影子版）。
- F7 两种规则：影子位每遍左移一格（`ABC'`→`AB'C`→`A'BC`→…）；影子个数每遍 +1（`ABC`→`ABC'`→`AB'C'`→`A'B'C'`）。

## 4. 出题规则要点

- **抽族**：同族每局配额 = `max(2, ⌈5 ÷ 族池数⌉)` —— 5 题 / 2 族时无法都 ≤2，只能均分 3+2，故按族池大小放宽；9 档必出 F6，10 档必出 F6/F7/F8（否则均匀抽族时一局可能完全没有影子，影子维度落空）。
- **选素材**：S1 每个符号来自不同组；S2/S3 所有符号同组，并排除上一题的答案图案（封死「跟上一题」）。组内除单元符号外还要留得下形近配额，否则换组。
- **干扰项优先级**（设计 §9.3）：答案的状态对（9–10 档必有）→ 同类近邻（优先本局已见）→ 序列内其他符号 → 局内已见图 → 同层新图。**S1 档的兜底也必须排除答案所在组**，否则兜底抽到同组图会把「跨类别」偷偷变成「同类别」。
- **问号位置**：1–7 档问号在末尾（6 档起末尾相位随机）；8–10 档序列内任意位置（含中段），序列恒含 2 个完整周期，任一单缺项在另一周期都有对照。
- **序列行容量**：最多 10 格（含问号）。单元长 4 时相位前缀被自动收窄，避免出现 12 格。
- **影子**：9–10 档图块带彩色/影子两种状态，**A 与 A′ 是两个不同图案**；答案本身也可能是影子块。

## 5. 提示 / 脚手架

| 档 | 显示什么 | 何时出现 |
|---|---|---|
| 1–2 | 每个重复单元用圆角底色框出，第二遍出现时轻闪一下（`transition` 变色 260ms，用训练时钟计时） | 常驻 |
| 3–5 | 文字「每 N 个一组」（N 按本题单元长度，混排时逐题适配） | 常驻 |
| 6–10 | 同上；8 档起文案变为「有一个位置空着，每 N 个一组，找找少了谁」；10 档按族给（影子族提示「影子也是不一样的队员，看看影子轮到谁？」，递增族提示「看看每一段是不是越来越长？」） | 本局答错 1 次后 |

- 脚手架**不影响计分**（得分只看正确数）。
- 9 档起首次进入时，「先试一下」会换成一道**不计分的影子引导题**（用影子和彩色对照，明确「影子是另一个队员」），答对后写入本地标记，之后不再重复。
- 10 档起题面常驻一行「影子也是不一样的队员」，满足「影子规则明示率 100%」。
- 设计里「家长可逐档关闭提示」尚未做设置入口；页面已把提示强度做成档位参数，后续接设置即可。

## 6. 计分口径与全局对齐

设计要求「升档 ≥80（5 题允许错 1），降档 <60」。
仓库全局口径是「满分 100 才升档」（`difficulty.uts` 的 `UPGRADE_SCORE`），且其他 27 个游戏共用。为不改公共行为，本游戏改为**在自己的计分函数里定义达标线**：

```
patternFindScore(答对, 5) = 答对 ≥ 4 ? 100 : round(答对 × 100 / 5)
```

- 错 0 或错 1 → **100 分**（= 全局口径下的升档；等价于设计的「≥80 升档」）
- 错 2 → 60 分（不低于设计的降档线 60）
- 错 3 → 40 分、错 4 → 20 分、全错 → 0 分（进入降档压力）

这样「一局容错恒定 1 题」，且 100 分仍是全仓统一的过关语义（与倒水小实验「达标给满分」同风格）。

## 7. 与设计文档的差异 / 实现选择

| 项 | 设计文档 | 本次实现 | 原因 |
|---|---|---|---|
| 难度指标 D | 表格给出固定数值，L4=10.10、L10=24.20 等 | 用同一公式按**实际参数**实时计算（L4=9.40、L5=12.10、L10=25.00），断言严格递增 | 文档表格与它自己给出的参数表存在算术不一致（文档也承认修正过一次）；公式与参数才是可执行的，D 只用于验证单调性 |
| F8 单元 | 前缀递增 + 块递增 | 只实现**块递增** | 无分隔符时「前缀递增」拼接（`ABABCABCD`）的分段边界有歧义，答案不能唯一读出；块递增靠重复次数即可无歧义 |
| 必出族 | 未明确 | 9 档必出 F6；10 档必出 F6/F7/F8 | 均匀抽族 + 同族配额下，一局可能完全不出现影子，影子维度会形同虚设 |
| 同族配额 | 同族每局 ≤2 题 | `max(2, ⌈5 ÷ 族池⌉)` | 5 题 / 2 族（2 档）时「都 ≤2」不可满足 |
| 干扰项「都已见」 | 3–4 档 100% | 非首题全用新图的比例 ≤20%（实测 9 档 0.06%） | 9–10 档的「答案状态对」本身就是序列里没出现过的新图，该两档不可能做到 100% |
| 提示可关闭 | 家长可逐档关闭 | 未做设置入口 | 需要新增设置页，另行安排 |
| 题面规则明示 | 题面或引导中 100% | 10 档起题面常驻一行；9 档靠入档引导题 | 兼顾低档屏幕简洁 |

## 8. 验收

```bash
node tools/test-pattern-find.cjs     # 档位配置表/难度单调/逐题结构/素材分层/计分口径/种子可复现
node tools/preview-pattern-find.cjs  # 浏览器近似预览：?start=1&level=1|5|8|10、?auto=1 自动答完
node tools/check-runtime-assets.mjs
```

回归实测（每档 400 局 = 2000 题）：

- 档位配置表与设计逐项一致；难度指标严格递增 `4.50 < 5.80 < 8.10 < 9.40 < 12.10 < 13.60 < 14.40 < 16.50 < 20.70 < 25.00`。
- 1–4 档**零**同组近邻干扰项（跨类别成立）；5–8 档形近干扰项覆盖 **100%**；9–10 档状态对干扰项 **100%**。
- 9 档：含影子题 493/2000（每局必出 F6），答案是影子 118 题；10 档：含影子题 849/2000，答案是影子 336 题。
- 唯一问号、选项唯一解、素材路径全部存在、相邻题答案零重复、答案位置分布均匀、同族配额零违规、必出族零缺失。
- 素材分层：S1 只用 easy 组、S2 只用 medium 同类别组与星球、S3 只用 similar/hard 细节组。

## 9. 待验收 / 已知风险

- **真机体验**：10 格序列在最小屏（375×667）是否需要再缩格、4 选项在小屏是否够大、单元框轻闪是否明显，需真机看一眼。
- **5–8 档依赖分组质量**：若某个同类别组近邻感不强（如 `medium-toys` 内是机器人与帆船），形近强度会打折。分组能力标记（s2/s3）在 `utils/pattern-find-levels.uts` 顶部集中维护，便于按真机反馈调整。
- **真人校准**：设计给出的「1–3 档 ≥80%、4–7 档 60–80%、8–10 档 40–60% 首局通过率」需真人样本验证；D 的权重（辨异负荷 > 工作记忆负荷）也待回归校准。
- 「找坏项」「双规律交替」「多维属性叠加」等题型按设计未纳入，留作后续扩展。
