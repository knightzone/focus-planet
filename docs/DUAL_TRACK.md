## 玩法

- 画面被**中线**横着切成两半，两个任务同时进行：
  - **上半（天空）**：蓝兔跃跃开火箭，躲避迎面而来的**小星球**；
  - **下半（大海）**：黄猫暖暖开潜艇，躲避游过来的**各种鱼**。
- 两个载具都**只能上下移动，且不能越过中线**：每一半纵向切成 **3 个停靠位**，**点哪一格就滑到哪一格，也可以按住上下拖动**（拖动按相对位移判定：走满 0.6 格挪一格，不依赖 clientY 零点，各平台一致）；两半各自独立，点/拖上面只动火箭、下面只动潜艇。
- 障碍物从右侧进入、以**恒定速度**向左移动；撞上就扣分并闪一下提示。
- 一局时长 **1—2 分钟**（随难度 60s → 120s），时间到即结算。

## 难度与计分

| 档 | 时长 | 障碍密度（生成间隔） | 起始分 |
| --- | --- | --- | --- |
| 1—2 | 60s | 1200 / 1100ms | 150 / 144 |
| 3—4 | 70s | 1000 / 900ms | 139 / 133 |
| 5—6 | 80 / 90s | 800 / 720ms | 128 / 122 |
| 7—8 | 100 / 110s | 640 / 560ms | 117 / 111 |
| 9—10 | 120s | 490 / 430ms | 106 / **100** |

- **难度只体现在障碍物密度**（生成间隔越来越短）+ 时长变长；障碍物速度全档一致（128px/s），不靠提速加难。
  2026-09-18 按手感把**密度整体降了一档**：每档改用原来上一档的间隔，最松一档再加长到 1200ms（上表已是降档后的值）。
- **起始分 150 → 100**：越难起步越低。**每次碰撞扣 10 分**，最低 0 分；不撞就保住起始分。
- 结算：`pages/result/result?gameId=dual-track&dimensionId=divided&…`，`scoreVersion=goal-v2`，
  `roundScores` 传单元素 `[score]`（与记忆与搜索/一心二用小司机同一约定，避免结果页平均后失真）。
- `gameScoreMax('dual-track')` 归到 200 档：起始分最高 150，若按 100 档会被 `utils/performance.uts` 夹成 100。
