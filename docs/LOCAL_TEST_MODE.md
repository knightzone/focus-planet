# 本地模拟登录

`utils/local-test.uts` 中 `LOCAL_TEST_MODE = true` 为临时测试开关。

- 打开 App 自动获得“本地测试”身份，无需手机验证码；首次填写儿童档案即可训练。
- 档案、训练记录、陪伴记录和难度使用独立本地测试存储；不会覆盖真实账号的同类数据。
- API 请求、成绩队列同步和更新检查暂停；不会写入假 token，也不会清除已有真实登录。账号绑定等在线功能不在本地测试范围。
- 家长锁仍有效；本地模式下登出仅提示，不清除真实账号。
- 切回 `false` 并重新编译后恢复真实登录及原数据，测试记录不会上传。发布前必须关闭此开关。
- 修改后执行 `ios/scripts/prepare-xcode.sh` 同步 iOS，再用 Xcode Run 重新安装。只同步文件不会更新手机上已安装的 App。
