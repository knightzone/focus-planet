# 星级展示与环绕奖励

## 星星能量（2026-09-13）

每颗星对应1点能量，按基础0–5星加过关1星计算，即 `reportStarCount(score)`，单局0–6点。基础星阈值20/40/60/80/90分，过关星独立要求>=100分。满分100分的关卡通关为5+1=6点，可超过100分的关卡也最多6点；不额外按超额分或120分动画发能量。

首页和星小屋均按已有训练记录逐条换算再求和，不再累加原始分数，也不在进入页面时重复发放。既有本地记录直接按新口径显示；清除记录后相应能量清零。结束页仍只展示基础0–5星，报告保留0–6星。

## 结束页

- 隐藏分数及数值表现指标，用主题星星与星球展示奖励；保留下一档难度和继续入口。
- 点亮星星数量0–5，未点亮位置使用淡色占位；分段为0–19→0、20–39→1、40–59→2、60–79→3、80–89→4、90及以上→5。
- 特殊动画门槛选择120分（统一常量 `CELEBRATION_SCORE`）。120及以上由五颗主题星星围绕主题星球旋转，不额外再绘制一排五星，避免出现十颗星。
- 8秒一周的椭圆轨道，前后层次和轻微大小变化；40ms更新一次，仅达标时创建动画计时器。后台暂停、返回恢复，组件卸载释放计时器，不使用新原生插件。
- 90分的五星不代表过关；100–119分达成挑战但无环绕；最高100分的游戏可以五星过关，不会触发120分动画。

## 报告与历史记录

- 每条训练记录继续显示真实分数，并用相同主题星展示0–6颗点亮数量。
- 前五颗沿用结束页映射；第六颗是独立过关星，score>=100即点亮，以浅绿色底区别于前五颗。
- 90–99分为五星，100–119分和120分及以上均为六星。第六颗与特殊动画不是同一阈值。
- 报告只引用静态 `ScoreStars`，不挂载环绕组件、不创建动画计时器。维度平均分继续用数值和条形表示，不把维度均分伪装成单个游戏过关。
