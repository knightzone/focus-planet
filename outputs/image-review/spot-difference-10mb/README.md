# 10MB预算压缩试听（图片）

最新状态：用户选择768×432版并授权替换，六张768样张已原样安装到运行目录；640版仅供对比。旧1280运行图保留在本目录previous-runtime。以下为最初试听记录。

不替换运行资源。使用cwebp从原PNG缩放、按每张32,000字节目标做10次质量搜索，m6；不是固定质量值。

- 推荐试听：640×360，三对6张共188,168字节，按低中高各50对估算9,408,400字节（9.41MB）。低档62,272字节/对，中档63,220，高档62,676。
- 备选：768×432，三对6张共185,234字节，150对外推9.26MB；预算相同时细节压缩更重。
- 对比原运行1280×720质量90，150对估算67.46MB；640版下降约86%。手机小图可用性需要用户确认，高难度细小纹样和放大浏览存在明显质量损失，不能当作无损压缩。
- 已输出每档A/B两张，两种尺寸共12张。`tools/preview-difference-compression.cjs`可重建。
- 本次仅样张外推，不保证所有未来场景都同样清晰；批量生成后需逐张限制体积并验收差异可辨性。尚未更改App素材或同步到Xcode。
