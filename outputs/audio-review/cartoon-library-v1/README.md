## 处理方向

- 动物升调 0.5–3 个半音且不加速，较低沉声源处理稍明显；鸟声只轻调，避免变尖。
- 汽车/火车/飞机升调 1–2 个半音，减弱高频刺激；不添加音乐、铃铛等可能提示或干扰答案的装饰。
- 乐器和铃声保持原音高，以短段、轻微削弱高频及平滑首尾适配整体听感；不把所有物品强行变成同一种高音。
- 单声道、44.1 kHz / 16 bit WAV，片段一般 0.5–2.6 秒；保留较短原声时可低于此范围。原始长音仅截取候选核心部分。
- 目标 RMS 约 -25 dBFS、采样峰值不高于 -12 dBFS，必要时优先限制峰值。不是严格的 LUFS 听感统一，实际响度和是否舒服仍需试听。数字电平不保证设备最大音量下安全或舒适。

## 筛选与验收状态

使用作者描述、RMS 事件边界与部分频谱检查选择裁剪位置。狗叫和钢琴做了人工边界调整。**未完成逐段听觉验收**，自动选出的段落可能仍包含背景声、过短起音或不适合儿童的音色；不能把“已导出”当作“已确认好听/温和”。

用户否定的旧狗叫没有采用。新候选来自 AustinXYZ 的 Chihuahua Puppy Bark 和 dtmendes 的幼犬录音；新来源也不等于已确认温和，需要重点试听。猪叫避开此前标题为 Angry Pig Oinking 的候选。

试听时先用偏低音量，并记录具体编号：是否能认出对象、是否尖锐/粗糙/突兀、是否喜欢卡通化程度。不合格段落更换来源，不通过增大音量弥补。确认后再做同类样本之间的主观响度微调和手机扬声器测试。

普通预渲染音频文件不依赖 iOS 专属音效处理 API；未进行 Android / HarmonyOS 播放验收，不能声称已完成跨端测试。
