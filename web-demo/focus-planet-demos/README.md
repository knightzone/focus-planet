# 专注星伴官网试玩组件

本目录是可直接放进官网静态资源目录的独立代码包，不依赖 Vue、uni-app、接口或账号。通过本地静态服务器打开 `index.html` 可预览；不要依赖 `file://` 方式验收音频。正式集成时，把整个目录复制到官网可访问的路径，保留 `assets/` 与 JS、CSS 的相对位置。

## 集成

在官网页面加入以下三行；路径根据部署位置调整：

```html
<link rel="stylesheet" href="/focus-planet-demos/focus-demos.css">
<div data-focus-planet-demos data-download-url="/download"></div>
<script src="/focus-planet-demos/focus-demos.js" defer></script>
```

`data-download-url` 可不填；填写时组件底部显示“了解 App”链接。脚本会自动挂载页面上的试玩容器；如果官网用客户端路由动态插入容器，可调用 `window.FocusPlanetDemos.mount(element)`。资源 URL 相对于 JS 文件解析，因此部署在子路径也可使用。样式统一以 `fpd-` 为前缀，避免污染官网现有页面。

本地预览示例：在此目录运行 `python3 -m http.server 8765`，然后访问 `http://127.0.0.1:8765/`。

## 当前固定关卡

| 游戏 | 内容 | 与 App 的关系 |
| --- | --- | --- |
| 影子配对 | 苹果、香蕉、葡萄三组；可点选或拖动 | 使用 App 当前彩图、影子及桌面背景，固定单轮 |
| 点球小将 | 三次射门；门将按中左中右移动，力量有效区 18–82% | 复用当前门将、球场、足球和低档力度/节奏；官网局数缩短 |
| 听音节奏 | 目标固定播放两次，三选一；选项可反复试听 | 使用 App 原始音频，官网固定一题；目标播放完不可重听 |

这只是宣传试玩：不请求服务端、不登录、不写本地存储、不产出 App 训练成绩或难度升级。官网没有实现完整 App 评分/课程流程；如更换关卡或加大题库，应单独评估内容、体积和版权。

## 部署验收

1. 用 HTTPS 部署整个目录；不要只上传 `index.html`。检查 `assets/` 图片和 MP3 均返回 200。
2. 在手机和电脑浏览器各试一次三款游戏；听音试玩必须在用户点“开始听目标”后播放，以符合浏览器自动播放限制。
3. 若站点设置了内容安全策略（CSP），允许本站图片、音频、样式和脚本；本组件不依赖第三方域名。
4. 下载链接由官网设置；包内没有虚构应用商店地址。

源素材来自当前 App 的 `static/images/runtime/` 和 `static/audio/audio-match/`，在此包内保留一份，以便官网独立部署。
